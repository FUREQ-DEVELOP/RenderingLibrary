# RenderingLibrary

独立したモジュール型描画ライブラリおよびSDKです。

## 開発目標

- DirectX 11 / DirectX 12対応
- C++20による実装
- 描画バックエンドの抽象化
- 描画機能の独立モジュール化
- 静的ライブラリおよび動的プラグインへの対応
- 他のゲームエンジンやアプリケーションへの組み込み

## 責務

描画処理、GPUリソース、シェーダー、描画パイプラインおよび描画機能を提供します。

ゲーム固有のロジックやエディター機能は対象外です。

## 開発環境

Windows / Visual Studio 2022 / C++20
